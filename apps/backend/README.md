# Airline Management System — Backend

Core backend workspace handling server-side architecture, business logic, and RESTful APIs for the Airline Management System (CSC290 Integrated Project I).

---

## Tech Stack

- **Framework:** NestJS (TypeScript)
- **ORM:** Prisma
- **Database:** PostgreSQL 16
- **Cache / Ephemeral Store:** Redis 7 (Seat Hold TTL, token storage, rate limiting)
- **Object Storage:** MinIO (S3-compatible bucket storage)
- **API Documentation:** OpenAPI / Swagger (`@nestjs/swagger`)
